# Idea
Cuarto de Máquinas es una tienda de hardware para armar PCs. El cliente elige una pieza por categoría (procesador, placa madre, memoria, placa de video, fuente, gabinete) y el sistema le avisa en el momento si algo no es compatible. Las piezas elegidas se reservan 10 minutos para que nadie se las lleve mientras decide. Si el setup está completo y es compatible, tiene un descuento y se puede confirmar.

**Problema que resuelve:** comprar piezas que después no encajan, o que se agotan mientras uno compara.
**Usuario:** cliente que arma su PC. No necesita cuenta.
**Fuera de alcance:** pagos reales, envíos, login, panel de administración.
